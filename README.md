# Portfolio

My personal portfolio website showcasing my skills & projects.

## 🚀 Quick Start

### Prerequisites
- **Node.js** (v14 or higher) - [Download](https://nodejs.org/)
- **npm** (comes with Node.js)

### Installation

```bash
# Install dependencies
npm install
```

### Development

```bash
# Start development server with live reload
npm run dev
# or
npm start
```

The site will automatically open at **http://localhost:8000** with **hot reload** enabled!

## 📋 Available Commands

| Command | Purpose | When to Use |
|---------|---------|-------------|
| `npm run dev` | Start dev server with live reload | Daily development |
| `npm start` | Alias for `npm run dev` | Quick start |
| `npm run clean` | Remove cache/build files | When troubleshooting |
| `npm run deploy` | Show deployment instructions | Before deployment |

## 🌐 Deployment

This is a static site, so you can deploy to:

- **GitHub Pages** (free) - `git push origin main`
- **Netlify** (free, with CI/CD) - Drag & drop folder
- **Vercel** (free, with CI/CD) - `vercel --prod`
- **AWS S3 + CloudFront** - For enterprise
- **Any static hosting service**

### GitHub Pages Deployment

1. Push code to GitHub repository
2. Go to Settings → Pages
3. Select branch (usually `main`)
4. Your site will be live at `username.github.io/repo-name`
